# 도구 공부 및 정리

## Antigravity
**Antigravity**는 Google DeepMind 팀에서 개발한 에이전트 기반 AI 코딩 어시스턴트(Agentic AI Coding Assistant)입니다.

### 주요 특징 및 기능

1. **자율적 에이전트 아키텍처 (Agentic Architecture)**
   - 복잡한 소프트웨어 개발 과제, 파일 수정, 시스템 명령 실행, 터미널 제어 및 브라우저 기반 인터랙션을 자율적으로 수행합니다.
   - 서브에이전트(Subagent) 생성 및 백그라운드 작업 처리로 분산 및 다단계 코딩 작업을 효과적으로 처리합니다.

2. **개발 환경 및 CLI 통합**
   - Antigravity IDE 및 커맨드라인 도구(`agy`)와 통합되어 프로젝트 전체 구조 파악, 리팩토링, 디버깅을 자동화합니다.

3. **강력한 확장 체계 (Customizations)**
   - **Skills**: 특정 워크플로우나 프레임워크에 대한 맞춤 지침서 등록
   - **Rules**: 코딩 컨벤션 및 스타일 가이드 강제
   - **Plugins & MCP**: 특화된 에이전트 툴 및 MCP(Model Context Protocol) 서버 연동 지원

4. **멀티모달 및 워크플로우 자동화**
   - 코드 작성뿐만 아니라 웹 애플리케이션 프로토타이핑, UI 생성/편집, 스케줄링 및 봇 기반 자동화를 지원합니다.
